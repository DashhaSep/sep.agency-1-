SEP — обновление: прелоадер и единая страница «Скоро будет».
Запуск: откройте index.html через локальный веб-сервер (например, VS Code Live Server).
Сохраните собственные папки images/ и fonts/ — здесь лежат только два логотипа проекта SMOOTH.
Прелоадер получает прогресс из реальной загрузки уникальных текстур, ждёт рендера 3D и шрифта Exposure. Если часть картинок не найдена, они не показываются чёрными карточками.
Файлы: index.html, soon.html, js/preloader.js, js/projects.js, js/awards.js, designrigs-gallery.js.
Фотографии и шрифты, не предоставленные пользователем, архив не содержит.
Готовая страница SMOOTH: projects/project-02.html; фотографии images/smooth/ как у пользователя.
Будущие проектные ссылки задаются в js/projects.js; пока отсутствующие идут на soon.html.
Внешние награды открываются в новой вкладке. Телефон не кликабелен.

Обновление:
- Полноэкранный 3D-прелоадер появляется только при первом успешном заходе в текущем браузере. После первой готовой сцены флаг сохраняется в localStorage.
- При возвращении с soon.html или проекта основная страница видна сразу, а
  WebGL-галерея появляется только после загрузки текстур и первого кадра.
- Новая soon.html оформлена по присланному макету (компактный чёрный текст,
  две кнопки, бежевый фон). Оранжевая кнопка включает фиолетовый курсор.
- Чтобы повторно протестировать первый запуск: очистите localStorage для домена.
